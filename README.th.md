# dev-crew

**ให้ AI ทำงานแบบหัวหน้าทีม dev ที่คุมทีมเล็กๆ**

โมเดลที่เก่งที่สุดหนึ่งตัวเป็นหัวหน้าทีม ทำหน้าที่วางแผน ตัดสินใจ ตรวจงาน และรวมงาน ส่วนโมเดลที่ถูกกว่าช่วยกันเขียนโค้ดไปพร้อมกัน skill นี้ออกแบบมาเพื่อให้ได้โค้ดคุณภาพดี ไม่เปลือง token กับงานจุกจิก และรายงานตามจริงว่าอะไรตรวจแล้ว อะไรยังไม่ได้ตรวจ ผลการวัดจริงดูได้ที่ [EVAL.md](EVAL.md)

## บทบาท

| บทบาท | ระดับโมเดล | งานที่ได้รับ |
|---|---|---|
| หัวหน้าทีม | เก่งที่สุด | ตัดสินใจ ตรวจงาน ไล่หาสาเหตุบั๊ก รวมงาน และสื่อสารกับผู้ใช้ |
| Builder | ระดับกลาง | งานที่ต้องใช้วิจารณญาณออกแบบ เช่น logic หลัก, API, state machine, หน้าจอ |
| Specialist | เล็กและเร็ว | งานที่สเปกชัดเจนแล้ว เช่น ฟังก์ชันพร้อม test, script, เอกสาร, ปรับหน้าตาตามธีมที่มีอยู่ |

## หลักการสำคัญ
1. เขียนไฟล์ `docs/decisions.md` ให้ทุก agent ยึดตาม ก่อนเริ่มแจกงาน
2. งานที่ทำพร้อมกันต้องแก้ไฟล์คนละชุด
3. เขียน brief ให้ชัดเหมือนสั่งงานผู้รับเหมา
4. หัวหน้าทีมรัน test ซ้ำเอง ไม่ส่งต่อคำรายงานของ agent โดยไม่ตรวจ
5. รายงานผู้ใช้ตามจริง รวมถึงสิ่งที่ยังไม่ได้ตรวจ
6. มีกฎความปลอดภัย เช่น ห้ามแก้ config ของเครื่อง ห้ามลบข้อมูล และห้าม push โดยไม่ถามผู้ใช้
7. ประหยัด token ด้วยการให้ agent ไปอ่านไฟล์เองแทนการแปะเนื้อหา จำกัดรายงานไม่เกิน 15 บรรทัด และเปิดไฟล์ใน `references/` เฉพาะตอนที่ต้องใช้

## ติดตั้ง (Claude Code แบบ plugin อัปเดตอัตโนมัติ)
```
/plugin marketplace add divlabco/dev-crew
/plugin install dev-crew@dev-crew
```
เปิดอัปเดตอัตโนมัติครั้งเดียว: พิมพ์ `/plugin` → **Marketplaces** → เลือก `dev-crew` → เปิด auto-update จากนั้น Claude Code จะเช็กเวอร์ชันใหม่ทุกครั้งที่เปิด ถ้าจะอัปเดตเองให้สั่ง `/plugin marketplace update dev-crew`

จากนั้นสั่งงาน เช่น *"ทำตามแผนนี้แบบทีม ใช้ Sonnet กับ Haiku"*

ถ้าใช้เครื่องมืออื่น เช่น Codex CLI, Gemini CLI, Cursor หรือ Copilot ให้ดูวิธีติดตั้งใน [README.md](README.md) และ `skills/dev-crew/references/solo-mode.md`

## ออกเวอร์ชันใหม่ (สำหรับผู้ดูแล)
1. แก้ไฟล์ แล้วเพิ่มรายการใน `CHANGELOG.md`
2. เปลี่ยน `version` ใน `.claude-plugin/plugin.json` เพราะผู้ใช้จะได้รับอัปเดตเมื่อเลขนี้เปลี่ยนเท่านั้น
3. commit แล้วสร้าง tag (`git tag v0.2.0`) จากนั้น `git push --follow-tags`
